Render OpenGL Triangle Strips With glPrimitiveRestartIndex

Rendering disconnected triangle strips in OpenGL traditionally required multiple draw calls or connecting meshes with invisible "degenerate" triangles, both of which introduce performance and memory overhead. Using glPrimitiveRestartIndex solves this problem by defining a special index value within an index buffer that acts as a delimiter, telling the GPU to break the current primitive and start a new strip immediately. This guide explains how to configure OpenGL, populate your index buffer with restart tokens, and issue a single draw call to render multiple disparate triangle strips.

How Primitive Restart Works

When drawing with GL_TRIANGLE_STRIP, OpenGL automatically constructs a triangle from every three consecutive vertex indices after the initial setup. When the GPU encounters the designated primitive restart index, it finishes the current primitive without drawing degenerate geometry, discards previous vertices from the strip assembly pipeline, and begins a new, independent triangle strip with the vertices that follow.

Step 1: Enable Primitive Restart

To activate the feature, call glEnable with the GL_PRIMITIVE_RESTART token:

glEnable(GL_PRIMITIVE_RESTART);

Step 2: Set the Restart Index

Use glPrimitiveRestartIndex to specify the unique integer value that represents the break in your index stream. Typically, the maximum representable value of the index type is chosen so it does not collide with real vertex data:

  • For 16-bit indices (GL_UNSIGNED_SHORT): 0xFFFF (65535)
  • For 32-bit indices (GL_UNSIGNED_INT): 0xFFFFFFFF (4294967295)
GLuint restartIndex = 0xFFFFFFFF;
glPrimitiveRestartIndex(restartIndex);

Step 3: Populate the Index Buffer

When building the Element Array Buffer (EBO), insert the defined restart index between each distinct strip:

// Two separate quads rendered as two triangle strips
GLuint indices[] = {
    // First Quad (Triangle Strip 1)
    0, 1, 2, 3,

    // Delimiter token
    0xFFFFFFFF,

    // Second Quad (Triangle Strip 2)
    4, 5, 6, 7
};

glBindBuffer(GL_ELEMENT_ARRAY_BUFFER, ebo);
glBufferData(GL_ELEMENT_ARRAY_BUFFER, sizeof(indices), indices, GL_STATIC_DRAW);

Step 4: Execute the Draw Call

Render the entire dataset using a standard indexed drawing command. Pass GL_TRIANGLE_STRIP as the primitive mode, along with the total count of indices, which includes the restart tokens:

glBindVertexArray(vao);
glDrawElements(GL_TRIANGLE_STRIP, 9, GL_UNSIGNED_INT, 0);
glBindVertexArray(0);

Modern OpenGL Alternative

In OpenGL 4.3 and above, or when using OpenGL ES 3.0+, you can also use glEnable(GL_PRIMITIVE_RESTART_FIXED_INDEX). This built-in mode eliminates the need to call glPrimitiveRestartIndex, automatically designating -1 (all bits set to 1, such as 0xFFFF or 0xFFFFFFFF depending on the data type passed to glDrawElements) as the restart token.
