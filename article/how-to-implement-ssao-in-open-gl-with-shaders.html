How to Implement SSAO in OpenGL with Shaders

Screen-Space Ambient Occlusion (SSAO) is a real-time rendering technique designed to approximate the soft contact shadows that occur when ambient light is blocked by nearby geometry. This article explains the fundamentals of SSAO and provides a step-by-step guide to implementing it using OpenGL framebuffer textures, sample kernels, and GLSL shaders, concluding with the blur pass required to produce smooth, realistic ambient shadowing.

Understanding Screen-Space Ambient Occlusion

Ambient occlusion simulates indirect lighting attenuation in crevices, corners, and intersecting surfaces. Traditional global illumination calculates this using expensive ray tracing. SSAO approximates this effect entirely in screen space as a post-processing effect, originally developed by Crytek.

By analyzing the depth buffer and surface normals of neighboring pixels, SSAO determines how "occluded" a given point is by surrounding geometry. If a fragment is surrounded by geometry that sticks out past it, ambient light reaches it less, and the fragment is darkened.

Step 1: The Geometry Pass (G-Buffer)

SSAO requires access to geometric data in view space. Before running the occlusion calculation, render the scene to a multi-render target (MRT) Framebuffer Object (FBO) to capture:

  1. Position Texture: The fragment's position in view space (usually formatted as GL_RGBA16F).
  2. Normal Texture: The surface normal vector in view space (GL_RGBA16F).
  3. Albedo/Depth: Standard color and linear depth values.

In the geometry fragment shader, write the view-space coordinates directly:

#version 330 core
layout (location = 0) out vec3 gPosition;
layout (location = 1) out vec3 gNormal;

in vec3 FragPos; // View-space position from vertex shader
in vec3 Normal;  // View-space normal from vertex shader

void main() {
    gPosition = FragPos;
    gNormal = normalize(Normal);
}

Step 2: Generating the Sample Kernel and Noise

SSAO samples points within a hemisphere oriented along the surface normal.

  1. Sample Kernel: Generate an array of 32 to 64 sample vectors in tangent space. These points should be distributed randomly within a unit hemisphere (where z > 0.0), with higher density toward the center of the sphere using an acceleration curve.
  2. Noise Texture: Generate a small 4x4 texture filled with random rotation vectors lying on the tangent plane (z = 0.0). By tiling this texture across the screen, you randomly rotate the hemisphere kernel per pixel, swapping regular banding artifacts for high-frequency noise that is easily blurred later.

Upload the sample points to the SSAO shader via uniform arrays or a Uniform Buffer Object (UBO), and bind the 4x4 noise texture to an active texture unit using GL_REPEAT.

Step 3: The SSAO Fragment Shader

The core calculation takes place on a screen-filling quad:

  1. Reconstruct Tangent Basis: Sample the noise texture and normal texture to construct a Tangent-Bitangent-Normal (TBN) matrix:

    vec3 normal = texture(gNormal, TexCoords).rgb;
vec3 randomVec = texture(texNoise, TexCoords * noiseScale).xyz;
vec3 tangent = normalize(randomVec - normal * dot(randomVec, normal));
vec3 bitangent = cross(normal, tangent);
mat3 TBN = mat3(tangent, bitangent, normal);

  2. Sample the Hemisphere: For each sample in the kernel, transform it to view space using the TBN matrix and offset it from the current fragment position:

    vec3 samplePos = fragPos + (TBN * samples[i]) * radius;

  3. Project to Screen Space: Project the sample position into clip space, then normalize device coordinates (NDC), and transform to texture coordinates [0.0, 1.0]:

    vec4 offset = projection * vec4(samplePos, 1.0);
offset.xyz /= offset.w;
offset.xyz = offset.xyz * 0.5 + 0.5;

  4. Depth Comparison: Read the depth at the offset texture coordinate from the G-Buffer position texture. If the actual surface depth is closer to the camera than the sample's depth, the sample is inside geometry and counts toward occlusion:

    float sampleDepth = texture(gPosition, offset.xy).z;
float rangeCheck = smoothstep(0.0, 1.0, radius / abs(fragPos.z - sampleDepth));
occlusion += (sampleDepth >= samplePos.z + bias ? 1.0 : 0.0) * rangeCheck;

  5. Final Factor: Average the accumulated occlusion and invert it (1.0 - (occlusion / kernelSize)) to obtain an ambient accessibility factor stored in a single-channel texture (GL_RED).

Step 4: The Blur Pass

The resulting SSAO texture contains high-frequency noise caused by the rotated sample kernel. To resolve this, render the occlusion texture into a second framebuffer using a bilateral or simple box blur.

A standard 4x4 box blur averages neighboring texels while preserving edges by rejecting samples that differ significantly in depth or normal direction.

Step 5: Final Composition

During the final lighting pass, sample the blurred SSAO texture using the current fragment's screen coordinates. Multiply the ambient lighting term by the SSAO factor:

vec3 ambient = ambientColor * texture(ssaoTexture, TexCoords).r;
vec3 color = ambient + diffuse + specular;

This darkens crevices naturally while leaving direct diffuse and specular lighting untouched.
