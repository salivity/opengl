Calculate Circle of Confusion in OpenGL Shaders

Depth of field (DoF) simulates real-world optical camera lenses by rendering scene elements sharply at a specific focal distance while progressively blurring regions in front of and behind that plane. At the core of this post-processing technique is the Circle of Confusion (CoC), a mathematical value representing the diameter of the blur circle cast by a single point of light onto the camera sensor. In an OpenGL fragment shader, calculating the CoC involves reading the fragment's non-linear depth buffer value, converting it to linear view space, and applying optical lens equations to determine the blur radius for subsequent blurring passes.

Step 1: Linearizing the Depth Buffer

The standard OpenGL depth buffer stores values non-linearly between \(0.0\) and \(1.0\), allocating more precision to fragments closer to the near clipping plane. To calculate a physically accurate or visually uniform blur, this depth must first be converted into linear view-space distance (\(z\)).

Given near plane \(n\) and far plane \(f\), the linear depth calculation inside the fragment shader is:

float getLinearDepth(float depthSample, float near, float far) {
    // Convert normalized device coordinates (NDC) z from [0, 1] to [-1, 1]
    float z_ndc = depthSample * 2.0 - 1.0;
    // Linearize to view-space distance
    return (2.0 * near * far) / (far + near - z_ndc * (far - near));
}

Step 2: Calculating CoC via the Thin-Lens Model

Real camera optics rely on the thin-lens equation. The physical diameter of the Circle of Confusion (\(C\)) at linear depth \(z\) depends on:

  • Focal length (\(f\))
  • Lens aperture diameter (\(A = \frac{f}{N}\), where \(N\) is the f-stop)
  • In-focus plane distance (\(z_f\))
  • Target depth (\(z\))

The formula to compute the physical CoC size is:

\[C = A \cdot \frac{|z - z_f|}{z} \cdot \frac{f}{z_f - f}\]

Converted into pixel space, \(C\) is scaled by the sensor size relative to the screen resolution to yield a blur radius in pixels.

Step 3: OpenGL Fragment Shader Implementation

In real-time rendering pipelines, the CoC is calculated per fragment and written to a render target (often the alpha channel of the color buffer or a separate single-channel texture).

#version 330 core

in vec2 TexCoords;
out vec4 FragColor;

uniform sampler2D depthTexture;
uniform sampler2D sceneColor;

uniform float uNear;
uniform float uFar;
uniform float uFocalDistance;  // Focus distance (z_f)
uniform float uFocalLength;     // Lens focal length (f)
uniform float uAperture;        // Lens aperture diameter (A)
uniform float uMaxBlurRadius;   // Clamp limit for blur size in pixels

void main() {
    float rawDepth = texture(depthTexture, TexCoords).r;
    float linearDepth = getLinearDepth(rawDepth, uNear, uFar);

    // Calculate signed Circle of Confusion
    // A signed value differentiates the foreground from the background
    float coc = uAperture * (linearDepth - uFocalDistance) / linearDepth 
                * (uFocalLength / (uFocalDistance - uFocalLength));

    // Scale to pixel radius and clamp to maximum allowable blur
    coc = clamp(coc, -uMaxBlurRadius, uMaxBlurRadius);

    // Normalize CoC into a [0, 1] or [-1, 1] range for post-process blur passes
    float normalizedCoC = coc / uMaxBlurRadius;

    vec3 color = texture(sceneColor, TexCoords).rgb;
    FragColor = vec4(color, normalizedCoC);
}

Step 4: Near vs. Far Field Handling

The sign of the calculated CoC designates its position relative to the focal plane:

  • Negative CoC (\(z < z_f\)): Indicates the near field (foreground). Foreground blur must bleed over sharp background pixels to prevent sharp silhouette artifacts.
  • Positive CoC (\(z > z_f\)): Indicates the far field (background). Background blur must be occluded by sharp foreground edges.

By storing the signed CoC value in the fragment shader output, subsequent separable Gaussian blur, bokeh, or disk-blur passes can evaluate whether surrounding samples belong to the foreground or background, ensuring geometrically accurate optical blur.
