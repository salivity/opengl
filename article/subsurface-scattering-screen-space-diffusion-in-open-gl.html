Subsurface Scattering & Screen-Space Diffusion in OpenGL

Subsurface scattering (SSS) is a critical rendering technique for simulating translucent materials like skin, marble, and wax, where light penetrates an object's surface, scatters internally, and exits at a different point. Screen-Space Subsurface Scattering (SSSS) approximates this computationally expensive phenomenon directly in post-processing by blurring irradiance using a diffusion profile. This guide explains the core principles of SSS and outlines a step-by-step approach to implementing screen-space diffusion profiles within an OpenGL pipeline.

Understanding Subsurface Scattering

Standard diffuse shading models, such as Lambertian reflection, assume light reflects immediately from the exact point of incidence. In reality, translucent materials allow light to enter the medium, interact with internal particles through multiple scattering events, and re-emerge at nearby surface locations.

This behavior softens hard shadow edges, causes color bleeding across surface contours (such as the distinct reddish hue seen when light passes through human ears), and creates a soft, lifelike appearance. Accurately modeling this via Bidirectional Surface Scattering Reflectance Distribution Functions (BSSRDF) requires expensive volumetric path tracing, making real-time approximations necessary for interactive applications.

The Screen-Space Diffusion Profile

A diffusion profile \(R(r)\) mathematically describes how light distribution diminishes as a function of the radial distance \(r\) from the entry point. Because different wavelengths of light scatter at different rates—red light typically travels farther through human tissue than green or blue light—diffusion profiles are spectral, containing unique scattering parameters for each color channel.

Jorge Jimenez’s Separable Subsurface Scattering method established that arbitrary diffusion profiles can be represented as a sum of Gaussians:

\[R(r) = \sum_{i=1}^{k} w_i \cdot G(r, \sigma_i)\]

Where:

  • \(w_i\) is the weight of each Gaussian term (per color channel).
  • \(\sigma_i\) is the variance (blur radius).

By decomposing the diffusion profile into a sum of Gaussians, the blur becomes separable, allowing a two-dimensional radial convolution to be executed as two sequential one-dimensional passes (horizontal and vertical), dramatically reducing computation time.

Implementing the Screen-Space Diffusion Pipeline in OpenGL

Applying this technique in OpenGL requires a multi-pass deferred rendering or post-processing architecture using Framebuffer Objects (FBOs).

1. Geometry and Irradiance Pass

Render the scene geometry to an off-screen FBO. You must store:

  • Diffuse Irradiance (RGB): The pure diffuse lighting (e.g., standard N·L light intensity without specular highlights or ambient terms), as only the diffuse component scatters.
  • Depth Buffer: Linearized view-space depth used to calculate world-space distances during blurring.
  • Surface Normals (optional, for bilateral filtering): To avoid blurring across sharp geometric discontinuities.
  • Material Mask: An identifier channel specifying which objects receive subsurface scattering and their respective profile strengths.

2. Separable Bilateral Filtering Passes

The diffuse texture is convolved using a depth-aware bilateral filter in two separate passes.

  • Horizontal Pass: Bind the diffuse buffer as input, execute a horizontal 1D blur kernel via a fragment shader, and render the intermediate result to a temporary texture.
  • Vertical Pass: Read from the intermediate texture, execute the vertical 1D blur kernel, and output the fully scattered diffuse result.
Core Filtering Logic in GLSL

The fragment shader samples neighboring pixels along the blur direction, scaling the sample offset by the surface's distance to preserve perspective correctness:

#version 450 core
out vec4 FragColor;

in vec2 TexCoords;

uniform sampler2D uDiffuseTex;
uniform sampler2D uDepthTex;

uniform vec2 uBlurDirection; // (1.0 / width, 0.0) or (0.0 / height, 1.0)
uniform float uSubsurfaceWidth;

// Precalculated Gaussian weights and offsets for the diffusion profile
const int NUM_SAMPLES = 7;
uniform vec3 uWeights[NUM_SAMPLES];
uniform float uOffsets[NUM_SAMPLES];

void main() {
    vec4 centerColor = texture(uDiffuseTex, TexCoords);
    float centerDepth = texture(uDepthTex, TexCoords).r;

    // Scale blur radius according to distance (world-space consistency)
    vec2 step = (uBlurDirection * uSubsurfaceWidth) / centerDepth;

    vec3 accumulatedLight = centerColor.rgb * uWeights[0];

    for (int i = 1; i < NUM_SAMPLES; ++i) {
        vec2 sampleOffset = step * uOffsets[i];

        // Sample both positive and negative directions
        vec2 uv1 = TexCoords + sampleOffset;
        vec2 uv2 = TexCoords - sampleOffset;

        float depth1 = texture(uDepthTex, uv1).r;
        float depth2 = texture(uDepthTex, uv2).r;

        // Bilateral weight to prevent bleeding across depth edges
        float depthWeight1 = exp(-abs(centerDepth - depth1) * 20.0);
        float depthWeight2 = exp(-abs(centerDepth - depth2) * 20.0);

        accumulatedLight += texture(uDiffuseTex, uv1).rgb * uWeights[i] * depthWeight1;
        accumulatedLight += texture(uDiffuseTex, uv2).rgb * uWeights[i] * depthWeight2;
    }

    FragColor = vec4(accumulatedLight, centerColor.a);
}

3. Final Composition Pass

Combine the scattered diffuse component with the remaining rendering components:

  • Non-scattered specular highlights (Phong, Blinn-Phong, or Cook-Torrance BRDF).
  • Transmittance (thin-object back-lighting, often sampled from a shadow map).
  • Ambient lighting and environment reflections.

Key Optimizations and Considerations

  1. Depth Discontinuities: A pure Gaussian blur bleeds color into surrounding, non-translucent geometry. The bilateral filter must strictly compare view-space depth differentials and surface normal orientations to cancel samples that lie outside the target surface.
  2. Profile Pre-computation: Derive Gaussian kernels and channel-specific weights on the CPU during initialization, then upload them as uniform arrays or within a uniform buffer object (UBO) to keep the fragment stage branch-free.
  3. Half-Resolution Execution: Since scattering acts as a low-pass filter on irradiance, this effect can be rendered into a half-resolution framebuffer and upsampled using a bilateral upsampling filter to minimize bandwidth consumption.
