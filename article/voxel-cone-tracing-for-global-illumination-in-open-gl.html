Voxel Cone Tracing for Global Illumination in OpenGL

This article explains how Voxel Cone Tracing (VCT) achieves real-time global illumination approximations using 3D textures in OpenGL. It covers the technical pipeline from conservative scene voxelization using the OpenGL pipeline, the generation of filtered anisotropic 3D mipmaps, and the final cone tracing pass used to approximate indirect diffuse irradiance and specular reflections.

The Core Pipeline

Voxel Cone Tracing approximates the rendering equation in real-time by substituting individual ray tests with volumetric cones traced through a pre-filtered spatial data structure. The implementation in OpenGL relies on three primary stages:

  1. Scene Voxelization: Converting triangle meshes into a 3D texture representation.
  2. Mipmap Filtering: Constructing an anisotropic volumetric hierarchy.
  3. Cone Tracing: Marching through the 3D texture along directional cones using trilinear filtering across mipmap levels.

1. Scene Voxelization via 3D Textures

The process begins by discretizing the static and dynamic scene geometry into a regular 3D grid stored as an OpenGL 3D texture (GL_TEXTURE_3D). This texture typically stores incoming radiance (RGB) and opacity/occlusion (A).

Viewport and Rasterization Setup

To rasterize geometry into a 3D volume, OpenGL requires setting a 2D viewport matching the resolution of the volume (e.g., \(256 \times 256\) or \(512 \times 512\)) and disabling depth testing (glDisable(GL_DEPTH_TEST)).

Geometry Shader Projection

Because traditional rasterization projects onto a single 2D plane, a Geometry Shader selects the dominant projection axis for each triangle to maximize rasterized fragment coverage:

  • Compute the face normal of the triangle.
  • Project the triangle along the axis corresponding to the largest absolute component of the normal (\(X\), \(Y\), or \(Z\)).
  • Pass the projected coordinates to the fragment shader alongside the original world-space position.

Conservative Rasterization

To ensure thin geometry does not create gaps in the voxel grid, conservative rasterization should be enabled via glEnable(GL_CONSERVATIVE_RASTERIZATION_NV) if supported, or manually expanded in the geometry shader by offsetting triangle edges outward.

Writing to the 3D Texture

In the fragment shader, depth output is discarded. Instead, OpenGL’s Image Load Store capability writes voxel data directly into an unbound 3D image buffer using imageStore or atomic blending operations:

layout(binding = 0, rgba8) uniform writeonly image3D u_VoxelTexture;

void main() {
    ivec3 voxelCoord = ivec3(worldToVoxel(v_WorldPos));
    vec4 surfaceData = vec4(calculateDirectLighting(), 1.0);
    imageStore(u_VoxelTexture, voxelCoord, surfaceData);
}

2. Anisotropic Mipmap Generation

Standard trilinear mipmapping blurs directional lighting information uniformly across all dimensions. Because visibility and lighting vary depending on the viewing angle, VCT requires directional filtering.

Why Anisotropic Filtering is Necessary

When tracing a cone, the footprint samples a region that represents occlusion and radiance from a particular direction. Standard isotropic downsampling causes light leaking through thin geometry and over-occludes surfaces.

Generating Directional Mips

To retain directional data, the application generates anisotropic mipmaps containing directional values for six cardinal axes (\(+X, -X, +Y, -Y, +Z, -Z\)):

  • A compute shader iteratively downsamples level \(N\) to level \(N+1\).
  • Each voxel at level \(N+1\) combines the sub-voxels of level \(N\), blending their color and opacity along the specific directional vector using front-to-back compositing: \[\alpha_{combined} = \alpha_1 + \alpha_2 \cdot (1 - \alpha_1)\] \[C_{combined} = C_1 + C_2 \cdot (1 - \alpha_1)\]

3. Cone Tracing and Sampling

Once the 3D texture pyramid is generated, a standard deferred or forward shading pass traces cones into the voxel volume to calculate indirect lighting.

Cone Representation and Geometry

A cone is defined by an origin \(\mathbf{O}\), a normalized direction vector \(\mathbf{D}\), and an opening half-angle \(\theta\).

As distance \(t\) along the cone axis increases, the cone's cross-sectional diameter \(d\) expands: \[d = 2 \cdot t \cdot \tan\left(\frac{\theta}{2}\right)\]

Level of Detail (LOD) Selection

The diameter \(d\) maps directly to a continuous mipmap level of the 3D texture: \[\text{LOD} = \log_2\left(\frac{d}{\text{VoxelSize}}\right)\]

In GLSL, hardware-accelerated sampling is performed using textureLod() on a sampler3D, allowing OpenGL to perform trilinear filtering across voxels and linear interpolation between adjacent mipmap levels automatically.

Raymarching and Accumulation Loop

The cone march evaluates steps along the vector \(\mathbf{D}\). At each step:

  1. Advance the sampling position proportional to the current cone diameter: \(t = t + d\).
  2. Calculate the corresponding mipmap level.
  3. Sample the anisotropic 3D texture using directional weights.
  4. Composite accumulated radiance and occlusion until the accumulated opacity reaches \(1.0\) or the trace exceeds maximum bounds:
vec4 traceCone(sampler3D voxelTex, vec3 origin, vec3 dir, float tanHalfAngle) {
    float t = voxelSize; // Offset by one voxel to avoid self-intersection
    vec4 accum = vec4(0.0);

    while (t < maxDistance && accum.a < 0.95) {
        float diameter = 2.0 * t * tanHalfAngle;
        float lod = log2(diameter / voxelSize);
        vec3 samplePos = origin + dir * t;
        vec3 uvw = worldToVoxelUV(samplePos);

        vec4 voxelSample = sampleDirectionalVoxel(voxelTex, uvw, dir, lod);

        // Front-to-back compositing
        accum.rgb += (1.0 - accum.a) * voxelSample.a * voxelSample.rgb;
        accum.a += (1.0 - accum.a) * voxelSample.a;

        t += max(voxelSize, diameter);
    }
    return accum;
}

4. Indirect Diffuse and Specular Evaluation

Indirect Diffuse (Irradiance)

Diffuse surfaces reflect light across an entire hemisphere oriented around the surface normal \(\mathbf{N}\).

  • To approximate the cosine-weighted hemisphere, multiple wide cones are cast (typically 5 to 9 cones).
  • One cone is aimed along \(\mathbf{N}\), and the remaining cones are distributed symmetrically around \(\mathbf{N}\) at roughly \(60^\circ\) angles with opening angles matching the distribution spacing (approximately \(\theta \approx 60^\circ\)).
  • The results are weighted by \(\cos(\theta)\) to compute indirect diffuse irradiance.

Indirect Specular (Reflections)

Specular reflections depend on surface roughness:

  • A single cone is traced along the reflection vector \(\mathbf{R} = \text{reflect}(\mathbf{V}, \mathbf{N})\).
  • The cone opening angle is defined by the surface roughness parameter: perfectly smooth surfaces use \(\theta \approx 0\) (approximating a standard ray), while rougher surfaces use wider cones that naturally sample higher mipmap levels, generating blurred reflections.
