Procedural Textures in OpenGL Fragment Shaders

Generating procedural textures entirely within an OpenGL fragment shader relies on evaluating mathematical functions per fragment to produce color, pattern, and depth without pre-rendered image files. By operating directly in GLSL (OpenGL Shading Language) on normalized coordinates, these algorithms yield memory-efficient, infinitely scalable, and seamlessly tileable surfaces. The core techniques encompass pseudo-random hash functions, gradient and value noise, cellular automata, fractal compounding, and coordinate space distortion.

1. Pseudo-Random Number Generation (Hash Functions)

Fragment shaders execute independently and without state, making traditional CPU pseudo-random generators unusable. Procedural textures instead use deterministic hash functions that map a 2D or 3D coordinate vector to a pseudo-random scalar between 0.0 and 1.0.

  • Trigonometric Hashes: Common legacy implementations use sine functions combined with large dot products, such as fract(sin(dot(uv, vec2(12.9898, 78.233))) * 43758.5453). While widely used, this method can exhibit precision artifacts on different GPU hardware.
  • Integer Bit-Mixing Hashes: Modern GLSL implementations utilize integer arithmetic and bitwise shifts (such as PCG or Jenkins-style hashes) on integer grid coordinates. These are hardware-deterministic and avoid floating-point rounding variance.

2. Value Noise and Gradient Noise

Smooth, natural-looking patterns require spatially coherent noise where adjacent fragments produce continuous, non-erratic values.

  • Value Noise: The shader divides space into an integer grid, hashes a random value at each corner, and calculates a smooth interpolation (using Hermite or quintic curves) across the fragment's sub-grid position.
  • Perlin (Gradient) Noise: Instead of assigning values directly to grid corners, Perlin noise assigns pseudo-random unit gradient vectors. The fragment computes the dot product between these gradients and the displacement vectors from the corners to the fragment, followed by a quintic polynomial blend. This eliminates the blocky directional artifacts of value noise.
  • Simplex Noise: Designed as a computational improvement over classic Perlin noise, Simplex noise divides space into a simplex grid (triangles in 2D, tetrahedra in 3D) rather than hypercubes. It significantly reduces the number of corner evaluations (\(N+1\) instead of \(2^N\) vertices), resulting in higher performance and fewer directional artifacts.

3. Cellular and Worley Noise (Voronoi)

Cellular noise algorithms model biological cells, stone, water caustics, and cracked surfaces by measuring distances to dynamically distributed feature points.

  • The algorithm divides the fragment's coordinates into an integer grid.
  • The shader inspects the current cell and its surrounding neighboring cells (a 3x3 kernel in 2D, or 3x3x3 in 3D), assigning a random feature point to each via a hash function.
  • It calculates the Euclidean, Manhattan, or Chebyshev distance from the fragment to each feature point.
  • By mapping the minimum distance (\(F_1\)), the second-closest distance (\(F_2\)), or their difference (\(F_2 - F_1\)), the shader generates distinct cellular membranes, crystalline facets, or cobblestone arrangements.

4. Fractal Brownian Motion (fBm)

Natural surfaces like clouds, terrain, and marble exhibit self-similarity across multiple spatial scales. Fractal Brownian Motion is not an independent noise generator, but an aggregation technique applied to base noise functions (typically Perlin or Simplex).

The shader iterates through multiple successive layers (octaves):

  • Frequency: Increased each step by a multiplier known as lacunarity (typically around 2.0).
  • Amplitude: Decreased each step by a factor known as persistence or gain (typically around 0.5).

By summing these scaled octaves, the shader transitions low-frequency broad structures into high-frequency micro-details in a single pass.

5. Domain Warping

Domain warping introduces fluid, non-rigid distortion by using the output of one procedural noise function to offset the input coordinates of another.

In GLSL, this involves evaluating a noise or fBm function to generate a 2D vector offset \(\vec{d}\), and then evaluating the primary noise function at the displaced coordinate \(\vec{p} + \vec{d}\). Nesting this process across multiple stages produces complex turbulence patterns resembling marble veins, atmospheric smoke, and viscous fluids.

6. Analytic Signed Distance Functions (SDFs)

For structured, non-organic procedural textures such as checkerboards, tiles, bricks, and weaves, shaders use analytic coordinate arithmetic:

  • Periodic Wrapping: Modulo and fractional operations (mod(), fract()) repeat local coordinate spaces indefinitely.
  • Signed Distance Fields: Mathematical distance formulas for primitives (boxes, circles, hexagons) are evaluated per pixel. Anti-aliased boundaries are computed using the fwidth() and smoothstep() functions, ensuring crisp, scale-independent vector transitions without rasterization artifacts.
