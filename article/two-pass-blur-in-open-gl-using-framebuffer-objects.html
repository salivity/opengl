Two-Pass Blur in OpenGL Using Framebuffer Objects

This article explains how to optimize image blurring in OpenGL by separating a 2D Gaussian blur into two sequential 1D passes—horizontal and vertical—using Framebuffer Objects (FBOs). It covers the mathematical motivation behind separable filtering, the architecture of ping-pong FBOs, and the step-by-step rendering process required to implement this technique efficiently in a graphics pipeline.

The Separability Advantage

A standard 2D Gaussian blur applies a convolution matrix across an \(N \times N\) area for every pixel, requiring \(N^2\) texture fetches per pixel. For an 11×11 kernel, that equates to 121 texture samples per pixel.

Because the 2D Gaussian function is mathematically separable, it can be decomposed into two independent 1D distributions:

\[G(x, y) = G(x) \times G(y)\]

By filtering along the horizontal axis first and then along the vertical axis, the sampling complexity drops from \(O(N^2)\) to \(O(2N)\). For an 11×11 kernel, this reduces texture fetches from 121 down to 22 per pixel, yielding a massive performance improvement without altering the mathematical result.

FBO Setup: Ping-Pong Buffering

To separate the blur, OpenGL cannot read from and write to the same texture simultaneously. You must use two Framebuffer Objects (FBOs) configured in a "ping-pong" arrangement to hold intermediate rendering results.

  1. Create Two FBOs and Textures: Generate two FBO handles and two 2D textures matching the dimensions of the render target (or a downscaled resolution for a bloom pass).
  2. Attach Textures: Attach one texture to each FBO using glFramebufferTexture2D(GL_FRAMEBUFFER, GL_COLOR_ATTACHMENT0, GL_TEXTURE_2D, textureID, 0).
  3. Set Texture Clamping: Set GL_TEXTURE_WRAP_S and GL_TEXTURE_WRAP_T to GL_CLAMP_TO_EDGE to prevent artifacts along the borders during sampling.

Pass 1: The Horizontal Blur

The first render pass isolates the horizontal component using the original scene texture as the source.

  1. Bind the Target: Bind the first FBO (FBO_A) via glBindFramebuffer(GL_FRAMEBUFFER, FBO_A).
  2. Set the Viewport: Configure glViewport to match the target texture dimensions.
  3. Bind the Source: Bind the original scene texture to a texture unit (e.g., GL_TEXTURE0).
  4. Configure Uniforms: Pass a horizontal direction vector (such as vec2(1.0, 0.0)) or a boolean flag horizontal = true to the blur fragment shader.
  5. Draw: Render a screen-aligned quad.

The fragment shader samples texels strictly along the horizontal axis:

// Horizontal offset calculation
vec2 tex_offset = 1.0 / textureSize(image, 0); // Size of single texel
for(int i = 1; i < 5; ++i) {
    result += texture(image, TexCoords + vec2(tex_offset.x * i, 0.0)).rgb * weight[i];
    result += texture(image, TexCoords - vec2(tex_offset.x * i, 0.0)).rgb * weight[i];
}

The resulting texture attached to FBO_A now contains a horizontally blurred version of the original image.

Pass 2: The Vertical Blur

The second render pass applies the vertical filter directly to the horizontally blurred image.

  1. Bind the Target: Bind the second FBO (FBO_B) or the default framebuffer (0) if this is the final output of your pipeline.
  2. Bind the Intermediate Source: Bind the texture from FBO_A to GL_TEXTURE0.
  3. Configure Uniforms: Set the direction vector to vertical (vec2(0.0, 1.0)) or set horizontal = false.
  4. Draw: Render the screen-aligned quad once more.

The fragment shader now samples strictly along the vertical axis:

// Vertical offset calculation
vec2 tex_offset = 1.0 / textureSize(image, 0);
for(int i = 1; i < 5; ++i) {
    result += texture(image, TexCoords + vec2(0.0, tex_offset.y * i)).rgb * weight[i];
    result += texture(image, TexCoords - vec2(0.0, tex_offset.y * i)).rgb * weight[i];
}

The output written to FBO_B (or the screen) represents the fully blurred 2D image, achieved in two lightweight render passes.

Additional Iterations

For stronger blurs without increasing the kernel radius, alternate between FBO_A and FBO_B in a loop:

  • Pass 1: Source = Original Scene \(\rightarrow\) Target = FBO_A (Horizontal)
  • Pass 2: Source = FBO_A Texture \(\rightarrow\) Target = FBO_B (Vertical)
  • Pass 3: Source = FBO_B Texture \(\rightarrow\) Target = FBO_A (Horizontal)
  • Pass 4: Source = FBO_A Texture \(\rightarrow\) Target = FBO_B (Vertical)

This ping-pong approach reuses the allocated memory while progressively widening the blur radius across minimal shader cycles.
