How GGX NDF Works in OpenGL PBR Shaders

The GGX/Trowbridge-Reitz normal distribution function (NDF) is the primary specular distribution model used in modern Physically Based Rendering (PBR) pipelines to describe surface roughness at the microfacet level. This article explains the theoretical role of the GGX NDF within the standard Cook-Torrance microfacet specular reflectance model, breaks down its mathematical formulation, and details its practical GLSL implementation within an OpenGL fragment shader.

The Role of the NDF in Cook-Torrance BRDF

In real-time physically based shading, surface specular reflection is commonly modeled using the Cook-Torrance specular Bidirectional Reflectance Distribution Function (BRDF):

\[f_{\text{specular}} = \frac{D \cdot F \cdot G}{4(\mathbf{N} \cdot \mathbf{V})(\mathbf{N} \cdot \mathbf{L})}\]

Where:

  • \(D\) is the Normal Distribution Function (NDF).
  • \(F\) is the Fresnel equation, describing reflectance at varying angles.
  • \(G\) is the Geometric attenuation/shadow-masking function.
  • \(\mathbf{N}\), \(\mathbf{V}\), \(\mathbf{L}\) are the surface normal, view direction, and light direction vectors.

The NDF, denoted as \(D\), statistically evaluates the alignment of microscopic surface facets (microfacets). Only microfacets whose normals align exactly with the half-vector \(\mathbf{H}\) (the halfway vector between the light direction \(\mathbf{L}\) and the view direction \(\mathbf{V}\)) reflect light directly into the camera. Thus, the NDF calculates the proportion of microfacets oriented toward \(\mathbf{H}\).

Mathematical Formulation of GGX/Trowbridge-Reitz

The Trowbridge-Reitz distribution, commonly referred to as GGX in computer graphics, is defined as:

\[D_{GGX}(\mathbf{N}, \mathbf{H}, \alpha) = \frac{\alpha^2}{\pi \left((\mathbf{N} \cdot \mathbf{H})^2 (\alpha^2 - 1) + 1\right)^2}\]

Key components of this formula include:

  • \(\mathbf{N} \cdot \mathbf{H}\): The cosine of the angle between the macro surface normal and the halfway vector, clamped between \(0.0\) and \(1.0\).
  • \(\alpha\): The roughness parameter. In modern PBR, Disney's observation is applied, mapping artist perceptual roughness linearly to \(\alpha = \text{roughness}^2\). Squaring the artist's input yields a more natural, uniform transition from smooth to rough appearances.

Visual Characteristics of GGX

Compared to older distributions such as Blinn-Phong or Beckmann, GGX exhibits a distinctive profile featuring a sharp, narrow specular peak accompanied by an extended, softly fading falloff ("long tails"). This behavior closely mirrors the empirical scattering properties of real-world materials, preventing the artificial "plastic" cutoff highlights characteristic of earlier shading models.

OpenGL GLSL Implementation

Within an OpenGL fragment shader, vectors must be normalized before computing the half-vector and evaluating the distribution function. Below is the standard implementation in GLSL:

// Function to compute the GGX/Trowbridge-Reitz Normal Distribution Function
float DistributionGGX(vec3 N, vec3 H, float roughness)
{
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float NdotH2 = NdotH * NdotH;

    float denom = (NdotH2 * (a2 - 1.0) + 1.0);
    denom = 3.14159265359 * denom * denom;

    return a2 / denom;
}

Integration in the Fragment Shader

In the main execution path of the fragment shader, the function is invoked during lighting evaluation:

#version 330 core
out vec4 FragColor;

in vec3 WorldPos;
in vec3 Normal;

uniform vec3 lightPos;
uniform vec3 camPos;
uniform float roughness;

void main()
{
    vec3 N = normalize(Normal);
    vec3 V = normalize(camPos - WorldPos);
    vec3 L = normalize(lightPos - WorldPos);
    vec3 H = normalize(V + L);

    // Prevent floating-point division by zero for extremely smooth surfaces
    float clampedRoughness = max(roughness, 0.001);

    float D = DistributionGGX(N, H, clampedRoughness);

    // D is subsequently multiplied by F and G in the full Cook-Torrance equation
    // ...
}

Clamping the roughness to a minimum value (such as 0.001) prevents division-by-zero errors when dealing with perfectly smooth surfaces (\(\alpha = 0\)), ensuring numerical stability across different hardware profiles. The resulting value \(D\) scales the intensity and shape of the specular highlight directly on the rendered geometry.
