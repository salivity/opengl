OpenGL Transform Feedback Mandatory Buffer Setup

Capturing stream output using OpenGL Transform Feedback requires a precise sequence of shader configurations, buffer allocations, and indexed binding states. This guide details the mandatory buffer setup necessary to intercept primitive data after the vertex or geometry processing stages and write it directly into GPU memory buffers without CPU round-trips.

1. Shader Varying Specification

Before linking your shader program, you must declare which output variables should be recorded into your feedback buffers. This is done via glTransformFeedbackVaryings.

const char* varyings[] = { "outPosition", "outVelocity" };
glTransformFeedbackVaryings(programID, 2, varyings, GL_INTERLEAVED_ATTRIBS);
glLinkProgram(programID);

You must choose one of two capture modes:

  • GL_INTERLEAVED_ATTRIBS: Multiple vertex attributes are packed contiguously into a single buffer.
  • GL_SEPARATE_ATTRIBS: Each attribute is directed to its own dedicated buffer index (up to GL_MAX_TRANSFORM_FEEDBACK_SEPARATE_ATTRIBS).

2. Buffer Creation and Memory Allocation

You must create standard OpenGL buffer objects and allocate sufficient memory to hold the generated primitive data.

GLuint tbo;
glGenBuffers(1, &tbo);
glBindBuffer(GL_TRANSFORM_FEEDBACK_BUFFER, tbo);
glBufferData(GL_TRANSFORM_FEEDBACK_BUFFER, bufferSizeBytes, NULL, GL_DYNAMIC_COPY);
glBindBuffer(GL_TRANSFORM_FEEDBACK_BUFFER, 0);

Using GL_DYNAMIC_COPY or GL_STATIC_READ is standard, depending on whether the captured data will immediately feed back into subsequent draw calls or be read back by the application.

3. Transform Feedback Object (TFO)

In modern OpenGL (version 4.0+ core profiles), state management should be handled through a Transform Feedback Object (TFO). The TFO stores the buffer bindings and capture states.

GLuint tfo;
glGenTransformFeedbacks(1, &tfo);
glBindTransformFeedback(GL_TRANSFORM_FEEDBACK, tfo);

4. Mandatory Indexed Buffer Binding

Standard target binding (glBindBuffer) is insufficient for Transform Feedback. The buffer must be bound to specific binding points using either glBindBufferBase or glBindBufferRange.

  • For GL_INTERLEAVED_ATTRIBS: Bind the single buffer to index 0.

    glBindBufferBase(GL_TRANSFORM_FEEDBACK_BUFFER, 0, tbo);

  • For GL_SEPARATE_ATTRIBS: Bind each buffer to its corresponding varying index declared in glTransformFeedbackVaryings.

    glBindBufferBase(GL_TRANSFORM_FEEDBACK_BUFFER, 0, tboPosition);
glBindBufferBase(GL_TRANSFORM_FEEDBACK_BUFFER, 1, tboVelocity);

5. Capture Execution

Once the buffer points are bound, capture is initiated and terminated around standard draw commands:

glEnable(GL_RASTERIZER_DISCARD); // Optional: Disables rasterization if only capturing data

glBindTransformFeedback(GL_TRANSFORM_FEEDBACK, tfo);
glBeginTransformFeedback(GL_POINTS); // Must match primitive type emitted

glDrawArrays(GL_POINTS, 0, vertexCount);

glEndTransformFeedback();
glBindTransformFeedback(GL_TRANSFORM_FEEDBACK, 0);

glDisable(GL_RASTERIZER_DISCARD);

The primitive type passed to glBeginTransformFeedback (GL_POINTS, GL_LINES, or GL_TRIANGLES) must strictly match the primitive topology output by the final active vertex-processing stage.
