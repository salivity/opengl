Mathematical Benefits of Variance Shadow Mapping

Variance Shadow Mapping (VSM) resolves one of real-time computer graphics' most persistent bottlenecks by reformulating the shadow determination problem using probability theory. In conventional shadow mapping, depth comparisons occur after texture sampling, preventing the use of standard hardware-accelerated filtering techniques. By storing statistical depth moments rather than raw scalar distances, VSM allows developers using OpenGL to leverage native texture filtering, mipmapping, and Gaussian blurs to produce smooth, anti-aliased shadows with minimal computational overhead.

The Linearity of Statistical Moments

Standard shadow mapping relies on a non-linear step function: a surface is either fully in shadow or fully lit based on the condition \(z_{fragment} \le z_{light}\). Because this step function is non-linear, applying a linear filter directly to the depth values before comparison produces mathematically incorrect results, manifesting as severe light bleeding or distorted penumbras. Consequently, Percentage Closer Filtering (PCF) must sample multiple depths individually, evaluate the step function for each, and average the boolean results in the fragment shader.

VSM bypasses this constraint by representing shadow caster distributions as continuous random variables. Instead of storing a single depth value \(z\), an OpenGL framebuffer writes two components to a two-channel floating-point texture (such as GL_RG32F or GL_RG16F):

  1. The first moment: the expected depth \(E[x] = z\)
  2. The second moment: the expected squared depth \(E[x^2] = z^2\)

Because the expectation operator \(E[\cdot]\) is strictly linear (\(E[aX + bY] = aE[X] + bE[Y]\)), linear combinations of moments equal the moments of the linear combination. This mathematical property allows these values to be filtered using any linear convolution operator prior to the shadow test.

Analytic Visibility via Cantelli's Inequality

When shading a fragment at depth \(t\), the rendering pipeline needs to determine the probability that an occluder exists in front of the fragment (\(P(x \ge t)\)). VSM computes an upper bound on this probability using Cantelli’s Inequality, a one-sided variant of Chebyshev’s Inequality.

First, the shader calculates the local variance (\(\sigma^2\)) from the retrieved moments:

\[\sigma^2 = E[x^2] - (E[x])^2\]

If the current fragment depth \(t\) is less than or equal to the filtered average depth \(\mu = E[x]\), the fragment is deemed completely lit (\(p = 1.0\)). If \(t > \mu\), the maximum probability of visibility is computed algebraically:

\[P(x \ge t) \le p_{max}(t) = \frac{\sigma^2}{\sigma^2 + (t - \mu)^2}\]

This closed-form rational equation approximates the percentage of the light source occluded without requiring iterative sampling. It yields a continuous scalar value between \(0.0\) and \(1.0\), naturally generating soft penumbras based on the local depth distribution.

OpenGL Hardware Acceleration Advantages

The mathematical shift from discrete boolean tests to continuous moment distributions unlocks several hardware-level optimizations in OpenGL:

  • Native Bilinear and Trilinear Filtering: OpenGL can use GL_LINEAR filtering parameters directly on the moment texture. Texture filtering units automatically blend texel moments during the sampling stage, eliminating the high shader instruction counts associated with multi-tap PCF.
  • Hardware Mipmapping: Mipmaps can be generated automatically using glGenerateMipmap(GL_TEXTURE_2D) because downsampling averages preserve moment validity. This reduces aliasing artifacts on distant surfaces and minimizes texture cache thrashing.
  • Anisotropic Filtering: High-angle geometry benefits directly from hardware anisotropic filtering, preserving sharp shadow silhouettes on surfaces viewed at grazing angles.
  • Separable Convolution Blurring: Large penumbras can be achieved by running rapid, two-pass separable Gaussian blur compute or fragment passes over the shadow map texture before the main geometry pass, decoupling filter kernel size from per-pixel shading cost.
