Eye Adaptation Using Parallel Reduction in OpenGL

Dynamic eye adaptation simulates how the human eye adjusts to varying light levels across a high dynamic range (HDR) scene. In modern rendering pipelines using OpenGL compute shaders, this effect is achieved by downsampling the rendered HDR frame through a process called parallel reduction to determine the average scene luminance. By iteratively summing luminance values in shared workgroup memory and applying temporal filtering across frames, the engine can smoothly alter exposure levels in real time without stalling the CPU or GPU pipelines.

1. Extracting Initial Logarithmic Luminance

The process begins by reading the HDR color buffer rendered in linear space. Standard luminance is calculated using standard photometric weights:

\[Y = 0.2126R + 0.7152G + 0.0722B\]

Because scenes can contain localized specular highlights or light sources with extreme values, a simple arithmetic mean would disproportionately skew the adaptation. Instead, the geometric mean is used, requiring the luminance values to be converted to the logarithmic domain:

\[\log(Y + \epsilon)\]

The small constant \(\epsilon\) prevents taking the logarithm of zero in completely dark pixels.

2. Parallel Reduction via Compute Shaders

Parallel reduction efficiently aggregates thousands or millions of pixel values into a single value by halving the active elements in logarithmic steps (\(O(\log N)\) complexity).

First Dispatch: Image to Workgroup Buffers

A compute shader is dispatched with a two-dimensional grid of workgroups (for example, \(16 \times 16\) threads per workgroup).

  1. Shared Memory Loading: Each thread reads one or more pixels from the HDR texture, computes the logarithmic luminance, and stores it in a shared memory array allocated per workgroup:

    shared float sharedLuminance[256];

  2. Synchronized Tree Reduction: The threads execute an iterative tree reduction. Half of the threads sum pairs of elements, followed by a memory barrier (barrier()) to ensure memory consistency across the workgroup:

    for (uint stride = 128; stride > 0; stride >>= 1) {
    if (gl_LocalInvocationIndex < stride) {
        sharedLuminance[gl_LocalInvocationIndex] += sharedLuminance[gl_LocalInvocationIndex + stride];
    }
    barrier();
}

  3. Partial Output: Once the stride drops to zero, the thread at index zero writes the workgroup's total sum into an intermediate Shader Storage Buffer Object (SSBO).

Subsequent Reduction Passes

If the initial dispatch outputs more elements than can fit in a single workgroup, subsequent 1D compute passes are chained together. Each pass reduces the previous buffer until only a single scalar value remains, representing the sum of all logarithmic luminance values in the scene.

The final step divides this sum by the total pixel count and computes the exponential:

\[L_{\text{target}} = \exp\left(\frac{1}{N} \sum \log(Y + \epsilon)\right)\]

3. Temporal Adaptation

Instantaneous exposure adjustments feel unnatural and cause flickering. To simulate gradual pupil dilation and constriction, the target luminance is blended with the adapted luminance from the previous frame using exponential decay:

\[L_{\text{adapted}} = L_{\text{prev}} + (L_{\text{target}} - L_{\text{prev}}) \cdot \left(1.0 - e^{-\Delta t \cdot \sigma}\right)\]

Where:

  • \(\Delta t\) is the frame delta time.
  • \(\sigma\) is the adaptation rate constant (different rates are often applied for adapting to dark versus bright areas).

This calculation typically runs in the final \(1 \times 1\) reduction compute step, reading the previous luminance and writing the new value into a dedicated \(1 \times 1\) texture or persistent uniform buffer.

4. Exposure Application

The resulting adapted luminance value is bound as a uniform or texture buffer in the post-processing tone mapping pass. The exposure value is calculated as:

\[\text{Exposure} = \frac{K}{L_{\text{adapted}}}\]

where \(K\) is a calibration constant (middle gray). The HDR color is scaled by this exposure factor prior to applying an operator like Reinhard, Filmic, or ACES, completing the eye adaptation loop.
