Flat Shading vs Smooth Shading in OpenGL

Flat shading and smooth shading represent two fundamentally different approaches to handling vertex attribute interpolation across rendered primitives in OpenGL. While flat shading assigns a single, uniform set of attributes from a designated "provoking vertex" to an entire primitive, smooth shading calculates a weighted interpolation of attributes across the primitive's surface. Understanding the operational differences between these two techniques involves examining how the OpenGL rasterizer processes vertex outputs, handles primitive geometry, and determines final fragment values.

The Mechanics of Flat Shading

In modern OpenGL, flat shading is governed by the flat interpolation qualifier in the OpenGL Shading Language (GLSL). When an output variable from the vertex shader is marked as flat, the rasterization stage does not interpolate the values between vertices. Instead, it selects one vertex to serve as the "provoking vertex" and copies its attributes directly to all fragments generated by that primitive.

The provoking vertex selection depends on the primitive type and the configuration set via glProvokingVertex(), which typically defaults to GL_LAST_VERTEX_CONVENTION in core profiles:

  • Triangles: The rasterizer extracts the attribute values from the designated provoking vertex (either the first or third vertex of the triangle) and broadcasts them across every fragment inside the triangle.
  • Lines: The attributes are sourced from either the starting or ending vertex of the line segment, making the entire line a single, solid color or property set.
  • Points: Since a point primitive inherently consists of only a single vertex, flat shading behaves identically to smooth shading for standard point operations.

Operationally, flat shading disables barycentric interpolation in the hardware rasterizer for the specified attribute, resulting in a distinct faceted, polygonal appearance where adjacent primitives exhibit abrupt boundary shifts.

The Mechanics of Smooth Shading

Smooth shading operates via the smooth interpolation qualifier, which is the default behavior in GLSL if no qualifier is specified. During smooth shading, the vertex shader computes values at each vertex, and the rasterizer calculates intermediate values across the interior of the primitive using perspective-correct barycentric interpolation.

  • Triangles: The rasterizer determines the location of each fragment center relative to the three triangle vertices, assigns barycentric weights, and calculates a uniquely blended attribute value for each fragment.
  • Lines: The rasterizer performs linear interpolation along the length of the segment between the two defined endpoints.

This interpolation allows for continuous transitions of colors, surface normals, and texture coordinates. When normals are smoothed, the fragment shader computes lighting independently for each fragment (Phong shading), creating the visual illusion of a curved, non-faceted surface across planar primitives.

Operational and Pipeline Differences

The primary operational contrast between the two modes lies in how the rasterizer feeds data to the fragment shader:

  1. Interpolation Overhead: Smooth shading requires the fixed-function rasterizer to perform perspective division and weighted sums for every interpolated attribute per fragment. Flat shading bypasses this calculation, simply duplicating the provoking vertex's register values across all generated fragments.
  2. Fragment Shader Input: Under flat shading, every fragment instance generated by a single primitive receives identical input values for that attribute. Under smooth shading, nearly every fragment receives unique, dynamically calculated values.
  3. Data Discontinuity: Flat shading introduces mathematical discontinuities at primitive borders, which is optimal for rendering hard-edged objects, low-poly aesthetics, or non-continuous metadata (such as material IDs). Smooth shading ensures \(C^0\) continuity across shared vertices with shared normals, making it the standard choice for organic shapes and continuous surfaces.
