Cook-Torrance Reflectance Model in OpenGL

This article provides a comprehensive overview of the Cook-Torrance microfacet reflectance model and demonstrates its implementation within an OpenGL fragment shader. You will learn the core theory behind microfacet specular reflection, the mathematical formulation of the \(D\), \(F\), and \(G\) functions, and how to combine these components in GLSL to produce physically based rendering (PBR) lighting effects.

What is the Cook-Torrance Model?

The Cook-Torrance model is a physically based Bidirectional Reflectance Distribution Function (BRDF) designed to simulate the reflection of light from rough, microfaceted surfaces. Traditional empirical models like Phong or Blinn-Phong approximate specular highlights using simplified mathematical curves. In contrast, Cook-Torrance models a surface as a collection of microscopic, perfectly reflective mirrors (microfacets), whose orientations determine how incoming light is scattered.

The total reflected radiance is divided into diffuse and specular components:

\[f_r = k_d f_{\text{diffuse}} + k_s f_{\text{specular}}\]

While \(f_{\text{diffuse}}\) is typically computed using standard Lambertian reflection (\(\frac{c}{\pi}\)), the specular term \(f_{\text{specular}}\) is defined by the Cook-Torrance formula:

\[f_{\text{cook-torrance}} = \frac{D \cdot F \cdot G}{4(\mathbf{N} \cdot \mathbf{V})(\mathbf{N} \cdot \mathbf{L})}\]

Where:

  • \(\mathbf{N}\) is the surface normal.
  • \(\mathbf{V}\) is the view direction vector pointing toward the camera.
  • \(\mathbf{L}\) is the light direction vector pointing toward the light source.
  • \(D\) (Normal Distribution Function): Approximates the ratio of microfacets aligned with the half-vector \(\mathbf{H}\).
  • \(F\) (Fresnel Equation): Calculates the ratio of light reflected versus refracted at different angles of incidence.
  • \(G\) (Geometric Shadowing/Masking Function): Accounts for the self-shadowing and occlusion of microfacets by neighboring facets.

Mathematical Formulation of D, F, and G

Modern real-time rendering pipelines generally use standard approximations for these three terms:

1. Normal Distribution Function (\(D\)): Trowbridge-Reitz GGX

The GGX distribution models specular highlights with realistic falloff and broad tails:

\[D_{GGX}(\mathbf{N}, \mathbf{H}, \alpha) = \frac{\alpha^2}{\pi \left((\mathbf{N} \cdot \mathbf{H})^2 (\alpha^2 - 1) + 1\right)^2}\]

Here, \(\alpha\) represents surface roughness (often mapped as \(\alpha = \text{roughness}^2\)).

2. Fresnel Equation (\(F\)): Fresnel-Schlick

The Schlick approximation simplifies the Fresnel reflection coefficient:

\[F_{\text{Schlick}}(\mathbf{V}, \mathbf{H}, F_0) = F_0 + (1 - F_0)(1 - (\mathbf{V} \cdot \mathbf{H}))^5\]

\(F_0\) represents the base reflectance of the surface at normal incidence (\(0^\circ\)). Non-metals generally have an \(F_0 \approx 0.04\), while metals use their albedo color as \(F_0\).

3. Geometry Function (\(G\)): Smith's Model with Schlick-GGX

Smith's method factors in both light direction (masking) and view direction (shadowing):

\[G(\mathbf{N}, \mathbf{V}, \mathbf{L}, k) = G_1(\mathbf{N}, \mathbf{V}, k) \cdot G_1(\mathbf{N}, \mathbf{L}, k)\]

\[G_1(\mathbf{N}, \mathbf{X}, k) = \frac{\mathbf{N} \cdot \mathbf{X}}{(\mathbf{N} \cdot \mathbf{X})(1 - k) + k}\]

For direct analytical lights, \(k = \frac{(\alpha + 1)^2}{8}\).

OpenGL Fragment Shader Implementation

Below is a complete GLSL fragment shader implementation demonstrating the Cook-Torrance evaluation for a single point light source.

#version 330 core

out vec4 FragColor;

in vec3 WorldPos;
in vec3 Normal;
in vec2 TexCoords;

uniform vec3 camPos;
uniform vec3 lightPos;
uniform vec3 lightColor;

uniform vec3 albedo;
uniform float metallic;
uniform float roughness;

const float PI = 3.14159265359;

// 1. Normal Distribution Function: Trowbridge-Reitz GGX
float DistributionGGX(vec3 N, vec3 H, float roughness) {
    float a = roughness * roughness;
    float a2 = a * a;
    float NdotH = max(dot(N, H), 0.0);
    float NdotH2 = NdotH * NdotH;

    float denom = (NdotH2 * (a2 - 1.0) + 1.0);
    denom = PI * denom * denom;

    return a2 / max(denom, 0.0000001);
}

// 2. Geometry Function: Schlick-GGX sub-function
float GeometrySchlickGGX(float NdotV, float roughness) {
    float r = (roughness + 1.0);
    float k = (r * r) / 8.0;

    float denom = NdotV * (1.0 - k) + k;
    return NdotV / denom;
}

// Smith's method combining shadowing and masking
float GeometrySmith(vec3 N, vec3 V, vec3 L, float roughness) {
    float NdotV = max(dot(N, V), 0.0);
    float NdotL = max(dot(N, L), 0.0);
    float ggx2 = GeometrySchlickGGX(NdotV, roughness);
    float ggx1 = GeometrySchlickGGX(NdotL, roughness);

    return ggx1 * ggx2;
}

// 3. Fresnel Equation: Fresnel-Schlick
vec3 FresnelSchlick(float cosTheta, vec3 F0) {
    return F0 + (1.0 - F0) * pow(clamp(1.0 - cosTheta, 0.0, 1.0), 5.0);
}

void main() {
    vec3 N = normalize(Normal);
    vec3 V = normalize(camPos - WorldPos);
    vec3 L = normalize(lightPos - WorldPos);
    vec3 H = normalize(V + L);

    // Compute attenuation
    float distance = length(lightPos - WorldPos);
    float attenuation = 1.0 / (distance * distance);
    vec3 radiance = lightColor * attenuation;

    // Base reflectivity: 0.04 for dielectrics, tinted by albedo for metals
    vec3 F0 = vec3(0.04);
    F0 = mix(F0, albedo, metallic);

    // Cook-Torrance BRDF components
    float NDF = DistributionGGX(N, H, roughness);
    float G   = GeometrySmith(N, V, L, roughness);
    vec3 F    = FresnelSchlick(max(dot(H, V), 0.0), F0);

    // Specular BRDF term
    vec3 numerator = NDF * G * F;
    float denominator = 4.0 * max(dot(N, V), 0.0) * max(dot(N, L), 0.0) + 0.0001;
    vec3 specular = numerator / denominator;

    // Energy conservation: specular (kS) vs diffuse (kD)
    vec3 kS = F;
    vec3 kD = vec3(1.0) - kS;
    kD *= 1.0 - metallic;

    // Lambertian diffuse
    vec3 diffuse = (kD * albedo) / PI;

    // Outgoing radiance
    float NdotL = max(dot(N, L), 0.0);
    vec3 Lo = (diffuse + specular) * radiance * NdotL;

    // Ambient term and tone mapping
    vec3 ambient = vec3(0.03) * albedo;
    vec3 color = ambient + Lo;

    // HDR to LDR tone mapping (Reinhard) and Gamma correction
    color = color / (color + vec3(1.0));
    color = pow(color, vec3(1.0 / 2.2));

    FragColor = vec4(color, 1.0);
}

Summary of the Shader Pipeline

  1. Vectors Setup: Normalize the surface normal \(\mathbf{N}\), view vector \(\mathbf{V}\), and light vector \(\mathbf{L}\). Compute the half-vector \(\mathbf{H} = \frac{\mathbf{V} + \mathbf{L}}{\|\mathbf{V} + \mathbf{L}\|}\).
  2. Material Setup: Interpolate dielectric base reflectivity (\(0.04\)) with the surface albedo according to the metallic parameter to establish \(F_0\).
  3. BRDF Calculation: Evaluate the \(D\), \(F\), and \(G\) functions. Compute specular radiance via \(\frac{DFG}{4(\mathbf{N}\cdot\mathbf{V})(\mathbf{N}\cdot\mathbf{L})}\).
  4. Energy Conservation: Balance diffuse reflection against Fresnel reflection using \(k_d = (1 - k_s)(1 - \text{metallic})\) to preserve physical energy constraints.
  5. Output Processing: Sum diffuse and specular contributions, apply ambient lighting, and perform tone mapping and gamma correction before final pixel output.
