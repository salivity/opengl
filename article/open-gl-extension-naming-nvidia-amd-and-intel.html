OpenGL Extension Naming: NVIDIA, AMD, and Intel

OpenGL utilizes standardized naming conventions to differentiate vendor-specific, proprietary extensions from standard, cross-vendor, and architecture-neutral features. This article explains the unique vendor identifiers assigned to NVIDIA, AMD, and Intel, demonstrating how these abbreviations appear in extension strings, function names, and token definitions across the OpenGL specification.

In OpenGL, proprietary hardware extensions allow GPU manufacturers to expose new hardware features before those capabilities are adopted into the core specification. Every vendor extension follows a uniform naming syntax across three primary elements: the extension name string, function prototypes, and enumeration constants (tokens).

The General Naming Pattern

  • Extension String: Follows the pattern GL_[VENDOR]_[feature_name].
  • Function Names: Follow the pattern gl[CommandName][VENDOR]().
  • Tokens / Constants: Follow the pattern GL_[TOKEN_NAME]_[VENDOR].

NVIDIA Identifier: NV and NVX

NVIDIA uses the vendor tag NV for its proprietary, officially supported extensions. When NVIDIA releases experimental or undocumented vendor extensions, it uses the tag NVX.

  • Extension Strings: GL_NV_mesh_shader, GL_NVX_gpu_memory_info
  • Functions: glDrawMeshTasksNV()
  • Tokens: GL_MESH_SHADER_NV, GL_GPU_MEMORY_INFO_DEDICATED_VIDMEM_NVX

AMD Identifier: AMD and ATI

AMD currently uses the vendor tag AMD for its modern extensions. However, extensions developed prior to and immediately following AMD's acquisition of ATI Technologies use the legacy ATI identifier. Both may be found in driver implementations.

  • Extension Strings: GL_AMD_pinned_memory, GL_ATI_meminfo
  • Functions: glNamedBufferStorageExternalAMD()
  • Tokens: GL_EXTERNAL_VIRTUAL_MEMORY_BUFFER_AMD, GL_VBO_FREE_MEMORY_ATI

Intel Identifier: INTEL

Intel uses the full vendor tag INTEL across all proprietary extensions designed for its integrated and discrete graphics architectures.

  • Extension Strings: GL_INTEL_fragment_shader_ordering, GL_INTEL_performance_query
  • Functions: glCreatePerfQueryINTEL(), glBeginPerfQueryINTEL()
  • Tokens: GL_PERFQUERY_SINGLE_CONTEXT_INTEL

Cross-Vendor and Multi-Vendor Distinction

Proprietary vendor extensions should not be confused with shared extensions:

  • EXT: Used when two or more hardware vendors support the same extension without Khronos Group standardization.
  • ARB or KHR: Used for extensions officially approved and ratified by the Khronos Architecture Review Board, representing broad cross-vendor industry consensus rather than a single manufacturer's proprietary implementation.
