Matrix Palette Skinning in OpenGL Shaders

Matrix palette skinning is a hardware-accelerated technique that deforms a 3D mesh smoothly across a moving skeletal armature. In an OpenGL pipeline, this process offloads vertex transformations to the GPU by passing a collection of bone transformation matrices—known as the matrix palette—into the vertex shader along with per-vertex bone indices and influence weights. By calculating a weighted average of these matrices for every vertex in real time, the shader produces natural deformations around joints without requiring the CPU to recompute the mesh geometry each frame.

The Matrix Palette

The matrix palette is an array of \(4 \times 4\) transformation matrices representing the current state of the skeleton. Each matrix in the palette transforms a vertex from its original position in "bind pose" (mesh space) into the current animated pose space of a specific bone.

In OpenGL, this palette is supplied to the vertex shader using one of three mechanisms depending on the required bone count and target hardware:

  • Uniform Arrays: For simple skeletons (typically under 64 to 128 bones), a standard uniform mat4 u_Bones[MAX_BONES]; array is sufficient.
  • Uniform Buffer Objects (UBOs): Provide higher capacity and faster updates between multiple shader programs.
  • Texture Buffer Objects (TBOs) or Shader Storage Buffer Objects (SSBOs): Used for complex rigs with hundreds of bones, bypassing standard uniform memory limits.

Each bone matrix is pre-multiplied on the CPU as:

\[\text{SkinningMatrix} = \text{CurrentBoneTransform} \times \text{InverseBindPoseMatrix}\]

The inverse bind pose matrix resets the vertex from model space relative to the bone's origin, and the current bone transform moves it to the animated position.

Per-Vertex Bone Attributes

To bind vertices to the skeleton, every vertex buffer object (VBO) includes two specialized vertex attributes:

  1. Bone Indices (ivec4 or uvec4): Pointers to the indices in the matrix palette that influence this vertex.
  2. Bone Weights (vec4): Scalar values defining how much influence each corresponding bone exerts on the vertex.

Most rendering pipelines limit bone influences to four per vertex, which aligns cleanly with standard four-component GLSL vector types (vec4). If a vertex is influenced by fewer than four bones, the unused components are padded with zero weights. Crucially, the sum of all weights for a single vertex must equal 1.0:

\[\sum_{i=0}^{n-1} \text{Weight}_i = 1.0\]

If weights do not sum to 1.0, the vertex will suffer from unintended scaling artifacts during animation.

Vertex Shader Implementation

Inside the GLSL vertex shader, skinning can be calculated by linearly blending the matrices first (Linear Blend Skinning), or by transforming the vertex position by each bone matrix individually and accumulating the results. Blending the matrices into a single composite skin matrix is generally more computationally efficient.

#version 330 core

layout(location = 0) in vec3 a_Position;
layout(location = 1) in vec3 a_Normal;
layout(location = 2) in ivec4 a_BoneIDs;
layout(location = 3) in vec4 a_Weights;

uniform mat4 u_ViewProjection;
uniform mat4 u_Bones[100];

out vec3 v_Normal;

void main()
{
    // Construct the blended skinning matrix
    mat4 skinMatrix = u_Bones[a_BoneIDs[0]] * a_Weights[0] +
                      u_Bones[a_BoneIDs[1]] * a_Weights[1] +
                      u_Bones[a_BoneIDs[2]] * a_Weights[2] +
                      u_Bones[a_BoneIDs[3]] * a_Weights[3];

    // Transform the vertex position
    vec4 skinnedPosition = skinMatrix * vec4(a_Position, 1.0);
    gl_Position = u_ViewProjection * skinnedPosition;

    // Transform normals (assuming uniform scaling)
    mat3 normalMatrix = mat3(skinMatrix);
    v_Normal = normalize(normalMatrix * a_Normal);
}

Handling Normals and Tangents

Surface vectors like normals and tangents must also be deformed by the skinning matrix to ensure lighting remains accurate as the mesh flexes. Because normals represent directions rather than points, they are transformed using only the upper-left \(3 \times 3\) portion of the blended skin matrix (mat3(skinMatrix)). If the bone transformations include non-uniform scaling, the normal must instead be transformed by the inverse transpose of the blended matrix to prevent distortion:

\[\text{NormalMatrix} = \text{transpose}(\text{inverse}(\text{mat3}(skinMatrix)))\]

Because calculating inverse matrices per-vertex in a shader is computationally expensive, pipelines that require non-uniform scaling typically calculate this orientation data or limit bone transforms to rigid rotations and uniform scales.
