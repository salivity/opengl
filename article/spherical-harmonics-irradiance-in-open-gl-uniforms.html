Spherical Harmonics Irradiance in OpenGL Uniforms

Spherical harmonics (SH) lighting projects low-frequency environment lighting onto an orthonormal sphere basis, reducing complex incoming radiance into a tiny set of scalar coefficients. Because Lambertian diffuse reflection behaves as an effective low-pass filter, developers can discard higher-frequency bands and represent entire ambient lighting environments using only the first nine coefficients per color channel. In modern OpenGL pipelines, this mathematical property allows irradiance fields to be packed into compact uniform arrays or symmetric matrices, enabling high-performance, textureless ambient diffuse lighting computed through a handful of vector operations in the fragment shader.

The Low-Frequency Nature of Irradiance

A diffuse surface integrates incoming radiance over a hemisphere weighted by the cosine of the angle between the incoming light and the surface normal. In their seminal 2001 work, Ravi Ramamoorthi and Pat Hanrahan demonstrated that this cosine convolution acts as an aggressive low-pass filter.

Because higher-frequency light variations are smoothed out during integration:

  • Over 99% of the reflected diffuse energy is captured using only the first three spherical harmonic bands (\(l = 0, 1, 2\)).
  • The basis requires \(n = (l + 1)^2\) basis functions, meaning only \(3^2 = 9\) coefficients are required per color channel.
  • For standard RGB lighting, this equates to exactly 27 floating-point values (108 bytes).

Encoding Coefficients for OpenGL Uniforms

Precomputing the SH coefficients involves projecting the environment map or light probes against the first nine spherical harmonic basis functions \(Y_{lm}(\theta, \phi)\). Once calculated, these values are combined with the cosine convolution weights (the diffuse reconstruction factors \(A_l\)) directly on the CPU.

In OpenGL, passing 27 floats can be handled in two main formats:

1. The Vector Array Approach

The simplest configuration stores the pre-scaled coefficients in a Uniform Buffer Object (UBO) or standard uniform array:

layout (std140) uniform SphericalHarmonics {
    vec4 shData[7]; // Packed array holding 9 vec3s across std140-aligned vectors
};

Alternatively, developers can declare an array of nine 3D vectors when alignment overhead is managed manually:

uniform vec3 u_SH[9];

2. The Symmetric Matrix Representation

Ramamoorthi and Hanrahan also showed that the quadratic expansion of order-3 SH irradiance can be rewritten into a \(4 \times 4\) symmetric matrix for each color channel.

The irradiance \(E(n)\) for a surface normal \(n = (x, y, z, 1)^T\) is evaluated as:

\[E(n) = n^T M n\]

This transforms the 9 coefficients into a matrix \(M\) where off-diagonal and diagonal terms represent the interactions of the normal components. In OpenGL, this requires three mat4 uniforms (u_MR, u_MG, u_MB), or a single compact array:

uniform mat4 u_SHMatrices[3]; // One matrix per color channel

Fragment Shader Evaluation

Evaluating the irradiance in the fragment shader does not require any expensive trigonometric operations. Because the basis functions for \(l \le 2\) are simple polynomials of the Cartesian coordinates \((x, y, z)\) of the unit normal vector, evaluation resolves to basic arithmetic.

For the direct vector formulation, the lighting calculation expands as:

vec3 EvaluateSH(vec3 n) {
    // Basis evaluation constants
    const float c1 = 0.429043;
    const float c2 = 0.511664;
    const float c3 = 0.743125;
    const float c4 = 0.886227;
    const float c5 = 0.247708;

    // Evaluate diffuse irradiance
    return c4 * u_SH[0] 
         + 2.0 * c2 * (u_SH[3] * n.x + u_SH[1] * n.y + u_SH[2] * n.z)
         + c1 * (u_SH[4] * (n.x * n.y) + u_SH[5] * (n.y * n.z) + u_SH[7] * (n.x * n.z))
         + c3 * u_SH[6] * (n.z * n.z - 1.0 / 3.0)
         + c5 * u_SH[8] * (n.x * n.x - n.y * n.y);
}

For the matrix formulation, evaluation is even more direct:

vec3 EvaluateSHMatrix(vec3 n) {
    vec4 v = vec4(n, 1.0);
    return vec3(
        dot(v, u_SHMatrices[0] * v),
        dot(v, u_SHMatrices[1] * v),
        dot(v, u_SHMatrices[2] * v)
    );
}

Performance Advantages

  • Zero Texture Bandwidth: Traditional ambient diffuse lighting requires sampling from a prefiltered cubemap, consuming texture units, cache bandwidth, and memory storage. SH uniforms completely eliminate texture sampling for ambient diffuse terms.
  • Ultra-Low Memory Footprint: At 108 bytes per probe, thousands of light probes can be loaded into an OpenGL Uniform Buffer Object (UBO) or Shader Storage Buffer Object (SSBO), enabling volumetric light grids with minimal VRAM consumption.
  • ALU Bound and Vectorized: Modern GPUs execute dot products and fused multiply-adds (MAD/FMA) faster than memory reads, making SH irradiance evaluation vastly more compute-efficient and cache-friendly than fetching from mipmapped textures.
