Soft Shadows in OpenGL with Percentage-Closer Filtering

Percentage-closer filtering (PCF) produces soft shadow edges in OpenGL by sampling multiple neighboring depth values from a shadow map, evaluating the depth test for each sample, and averaging the boolean results into a fractional visibility factor. Unlike standard shadow mapping, which performs a single depth comparison resulting in hard, pixelated borders, PCF smooths the transition between light and shadow by filtering the shadow comparison results rather than the raw depth values.

The Limitation of Standard Shadow Mapping

In basic shadow mapping, a fragment's position is transformed into light space, and its projected depth is compared against the single closest depth value stored in the shadow map texture. This produces a binary outcome: the fragment is either fully illuminated (1.0) or completely in shadow (0.0). Because shadow maps have a finite resolution, this binary evaluation magnifies texel boundaries, resulting in noticeable staircase artifacts and harsh, aliased edges on the geometry.

Directly applying linear filtering to the shadow map's depth values does not fix this problem. Averaging depth values before the comparison yields nonsensical depth measurements near geometry edges, causing severe shadow acne and rendering artifacts.

The Percentage-Closer Filtering Algorithm

Percentage-closer filtering solves aliasing by reversing the order of operations: it performs the depth comparisons first and filters the results second.

  1. Coordinate Transformation: The fragment's world-space position is transformed into light clip space using the light's view-projection matrix. A perspective divide is applied, and the coordinates are mapped from the normalized device coordinate range [-1, 1] to the texture coordinate range [0, 1].
  2. Kernel Sampling: Instead of sampling a single texel at the transformed UV coordinates, the fragment shader defines a sampling kernel—such as a 3x3, 4x4, or Poisson disk distribution—around the target UV point.
  3. Offset Calculation: Each sample offset is scaled by the inverse of the shadow map's dimensions (1.0 / textureSize(shadowMap, 0)), ensuring that samples align precisely with adjacent texels.
  4. Per-Sample Comparison: For every offset in the kernel, the fragment shader compares the current fragment’s light-space depth (minus an appropriate depth bias to eliminate shadow acne) with the depth stored in the shadow map at that offset. Each test returns 1.0 if the sample is illuminated or 0.0 if it is occluded.
  5. Averaging: The shader sums the results of all individual comparisons and divides the total by the number of samples taken.

The resulting value is a floating-point number between 0.0 and 1.0 representing the percentage of the fragment's footprint that is illuminated. Multiplying the light's diffuse and specular contributions by this factor produces a smooth gradient along shadow boundaries, simulating an antialiased penumbra.

Hardware-Accelerated PCF in OpenGL

OpenGL provides native hardware support for PCF, enabling efficient 2x2 bilinear percentage-closer filtering directly on the GPU without requiring multiple manual texture fetches in the shader.

To configure hardware PCF:

  • Set the shadow texture's comparison mode using glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_COMPARE_MODE, GL_COMPARE_REF_TO_TEXTURE).
  • Define the comparison operator using glTexParameteri(GL_TEXTURE_2D, GL_TEXTURE_COMPARE_FUNC, GL_LEQUAL).
  • Set the texture filtering parameters (GL_TEXTURE_MIN_FILTER and GL_TEXTURE_MAG_FILTER) to GL_LINEAR.

In the GLSL fragment shader, the shadow map is declared as a sampler2DShadow instead of a standard sampler2D. When sampling with texture(shadowMap, vec3(uv, currentDepth)), the GPU automatically samples the four nearest texels, compares each against currentDepth, and bilinearly interpolates the four comparison results.

Developers can combine this native hardware feature with a custom multi-tap sampling loop in GLSL. By running a manual kernel over a sampler2DShadow, each tap evaluates a pre-filtered 2x2 footprint, producing high-quality, wide penumbras with significantly fewer shader instructions and reduced performance overhead.
