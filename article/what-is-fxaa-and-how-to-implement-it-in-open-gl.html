What is FXAA and How to Implement It in OpenGL

Fast Approximate Anti-Aliasing (FXAA) is a popular screen-space post-processing technique designed to smooth jagged edges (aliasing) with minimal performance overhead. This article explains the core principles of FXAA, contrasts it with traditional geometry-based anti-aliasing methods, and details the step-by-step logic required to construct an FXAA pass using modern OpenGL Shading Language (GLSL).

Understanding Fast Approximate Anti-Aliasing (FXAA)

Developed by Timothy Lottes at NVIDIA, FXAA targets the visual artifacts known as "jaggies" directly on the rendered 2D frame. Unlike traditional Multi-Sample Anti-Aliasing (MSAA) or Super-Sample Anti-Aliasing (SSAA), which rely on capturing multiple sub-pixel geometric samples during rasterization, FXAA is purely an image-space algorithm.

Because it operates on the final color buffer as a post-processing pass, FXAA offers several distinct advantages:

  • High Performance: It requires only one full-resolution color buffer, minimizing memory bandwidth and GPU execution time.
  • Compatibility with Deferred Rendering: Traditional MSAA struggles with deferred rendering pipelines due to the separation of geometry and lighting passes. FXAA processes the final composited image, making it fully compatible with any shading pipeline.
  • Alpha-Tested Geometry Smoothing: FXAA can smooth edges inside textures, such as foliage or chain-link fences, which geometry-based MSAA inherently misses.

The primary trade-off of FXAA is a slight reduction in overall image sharpness, as it acts as a selective blur over high-contrast transitions.

The FXAA Pipeline

The FXAA algorithm identifies contrast boundaries where aliasing occurs and blurs across those boundaries based on local gradient direction and edge distance. The process breaks down into five stages:

  1. Luminance Calculation: Convert local RGB values to perceptual brightness (luminance) to detect contrast visually.
  2. Local Contrast Check: Sample surrounding pixels to determine if the local contrast exceeds a sensitivity threshold. If contrast is low, the pixel is skipped to preserve performance.
  3. Edge Direction Detection: Evaluate horizontal and vertical gradients to determine whether the edge runs primarily horizontally or vertically.
  4. Edge Boundary Traversal: Walk along the detected edge in both directions to find where the contrast boundary ends.
  5. Sub-pixel Offset & Resampling: Compute an interpolation offset based on the pixel's distance to the nearest edge endpoint, then sample the texture using bilinear filtering at the offset coordinate.

Constructing FXAA in an OpenGL Fragment Shader

In OpenGL, FXAA is executed via a full-screen quad fragment shader. The input is the rendered scene texture, and the output is the anti-aliased frame.

1. Luminance Calculation

Human vision is more sensitive to green than red or blue. The shader uses a dot product to calculate perceived luminance:

#version 330 core

in vec2 TexCoords;
out vec4 FragColor;

uniform sampler2D screenTexture;
uniform vec2 inverseScreenSize; // vec2(1.0 / width, 1.0 / height)

// RGB to Luminance conversion
float rgb2luma(vec3 rgb) {
    return dot(rgb, vec3(0.299, 0.587, 0.114));
}

2. Early Exit via Contrast Threshold

To conserve GPU resources, compute the luminance of the center pixel and its four direct orthogonal neighbors (North, South, East, West). If the difference between the minimum and maximum luminance is lower than a dynamic threshold, anti-aliasing is skipped:

#define EDGE_THRESHOLD_MIN 0.0312 // Trims computation in dark areas
#define EDGE_THRESHOLD_MAX 0.125  // Minimum local contrast to apply FXAA

void main() {
    vec3 colorCenter = texture(screenTexture, TexCoords).rgb;
    float lumaCenter = rgb2luma(colorCenter);

    float lumaDown  = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2(0, -1)).rgb);
    float lumaUp    = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2(0,  1)).rgb);
    float lumaLeft  = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2(-1, 0)).rgb);
    float lumaRight = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2( 1, 0)).rgb);

    float lumaMin = min(lumaCenter, min(min(lumaDown, lumaUp), min(lumaLeft, lumaRight)));
    float lumaMax = max(lumaCenter, max(max(lumaDown, lumaUp), max(lumaLeft, lumaRight)));
    float lumaRange = lumaMax - lumaMin;

    if (lumaRange < max(EDGE_THRESHOLD_MIN, lumaMax * EDGE_THRESHOLD_MAX)) {
        FragColor = vec4(colorCenter, 1.0);
        return;
    }

3. Estimating Edge Orientation

Include the diagonal corner pixels (North-West, North-East, South-West, South-East) to determine whether the edge is horizontal or vertical:

    float lumaDownLeft  = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2(-1, -1)).rgb);
    float lumaUpRight   = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2( 1,  1)).rgb);
    float lumaUpLeft    = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2(-1,  1)).rgb);
    float lumaDownRight = rgb2luma(textureOffset(screenTexture, TexCoords, ivec2( 1, -1)).rgb);

    // Combine orthogonal and diagonal variations
    float edgeHorizontal = abs(-2.0 * lumaLeft + lumaDownLeft + lumaUpLeft) +
                           abs(-2.0 * lumaCenter + lumaDown + lumaUp) * 2.0 +
                           abs(-2.0 * lumaRight + lumaDownRight + lumaUpRight);

    float edgeVertical   = abs(-2.0 * lumaUp + lumaUpLeft + lumaUpRight) +
                           abs(-2.0 * lumaCenter + lumaLeft + lumaRight) * 2.0 +
                           abs(-2.0 * lumaDown + lumaDownLeft + lumaDownRight);

    bool isHorizontal = (edgeHorizontal >= edgeVertical);

4. Edge Traversal and Gradient Sampling

Identify the side of the edge with the highest gradient. Then, step along the edge perpendicular to that gradient to locate the end of the boundary:

    // Determine the step direction perpendicular to the edge
    float stepLength = isHorizontal ? inverseScreenSize.y : inverseScreenSize.x;
    
    float luma1 = isHorizontal ? lumaDown : lumaLeft;
    float luma2 = isHorizontal ? lumaUp : lumaRight;
    float gradient1 = luma1 - lumaCenter;
    float gradient2 = luma2 - lumaCenter;

    bool is1Steeper = abs(gradient1) >= abs(gradient2);
    float gradientScaled = 0.25 * max(abs(gradient1), abs(gradient2));

    // Shift coordinates halfway toward the adjacent pixel with the steepest gradient
    vec2 currentUv = TexCoords;
    if (isHorizontal) {
        currentUv.y += (is1Steeper ? -stepLength : stepLength) * 0.5;
    } else {
        currentUv.x += (is1Steeper ? -stepLength : stepLength) * 0.5;
    }

    // Step vector along the edge boundary
    vec2 stepOffset = isHorizontal ? vec2(inverseScreenSize.x, 0.0) : vec2(0.0, inverseScreenSize.y);
    
    vec2 uvPos = currentUv + stepOffset;
    vec2 uvNeg = currentUv - stepOffset;

    float lumaEndPos = rgb2luma(texture(screenTexture, uvPos).rgb);
    float lumaEndNeg = rgb2luma(texture(screenTexture, uvNeg).rgb);
    
    // Search for edge ends
    bool reachedPos = abs(lumaEndPos - lumaCenter) >= gradientScaled;
    bool reachedNeg = abs(lumaEndNeg - lumaCenter) >= gradientScaled;

    #define ITERATIONS 12
    for (int i = 2; i < ITERATIONS; ++i) {
        if (!reachedPos) {
            uvPos += stepOffset;
            lumaEndPos = rgb2luma(texture(screenTexture, uvPos).rgb);
            reachedPos = abs(lumaEndPos - lumaCenter) >= gradientScaled;
        }
        if (!reachedNeg) {
            uvNeg -= stepOffset;
            lumaEndNeg = rgb2luma(texture(screenTexture, uvNeg).rgb);
            reachedNeg = abs(lumaEndNeg - lumaCenter) >= gradientScaled;
        }
        if (reachedPos && reachedNeg) break;
    }

5. Sub-pixel Offset Calculation and Final Sampling

Calculate the distance to both ends of the edge. The final texture offset is computed as a proportion of the distance to the closest boundary, blending the edge:

    float dstPos = isHorizontal ? (uvPos.x - TexCoords.x) : (uvPos.y - TexCoords.y);
    float dstNeg = isHorizontal ? (TexCoords.x - uvNeg.x) : (TexCoords.y - uvNeg.y);

    bool isPosCloser = dstPos < dstNeg;
    float dstCloser = min(dstPos, dstNeg);
    float edgeLength = dstPos + dstNeg;

    // Sub-pixel offset applied in the direction of the steep gradient
    float pixelOffset = -dstCloser / edgeLength + 0.5;

    vec2 finalUv = TexCoords;
    if (isHorizontal) {
        finalUv.y += pixelOffset * (is1Steeper ? -stepLength : stepLength);
    } else {
        finalUv.x += pixelOffset * (is1Steeper ? -stepLength : stepLength);
    }

    // Bilinear hardware filtering produces the smoothed result
    FragColor = vec4(texture(screenTexture, finalUv).rgb, 1.0);
}

By leveraging hardware-accelerated bilinear texture sampling during the final read, this shader blends adjacent pixels along the detected geometric discontinuity, producing a smooth anti-aliased output at very low computational cost.
