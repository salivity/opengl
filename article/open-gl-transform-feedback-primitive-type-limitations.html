OpenGL Transform Feedback Primitive Type Limitations

Transform feedback in OpenGL allows developers to intercept and capture vertex attributes generated by the vertex, tessellation, or geometry shading stages directly into buffer objects before rasterization occurs. However, this process imposes strict constraints on the geometric primitive types that can be recorded. This article outlines the fundamental primitive limitations inherent to OpenGL transform feedback, the matching rules enforced between draw calls and capture modes, and how complex topologies are handled during capture.

The Allowed Primitive Modes

When initiating transform feedback via the glBeginTransformFeedback call, OpenGL strictly limits the target capture mode to one of three fundamental primitive categories:

  • GL_POINTS
  • GL_LINES
  • GL_TRIANGLES

No other primitive types—such as line loops, line strips, triangle strips, triangle fans, polygons, or adjacency primitives—are valid arguments for glBeginTransformFeedback. Passing any mode other than these three generates a GL_INVALID_ENUM error.

Pipeline Matching Restrictions

OpenGL enforces a strict correlation between the primitive mode specified in glBeginTransformFeedback and the primitives emitted by the last active processing stage before rasterization:

  1. With a Geometry Shader Active: The primitive output type declared in the geometry shader (layout(...) out;) must correspond directly with the transform feedback mode. If the geometry shader outputs points, the feedback mode must be GL_POINTS. If it outputs line_strip, the feedback mode must be GL_LINES. If it outputs triangle_strip, the feedback mode must be GL_TRIANGLES. Any mismatch results in a GL_INVALID_OPERATION error when drawing.
  2. Without a Geometry Shader: The primitive type supplied by the draw call (e.g., glDrawArrays or glDrawElements) must naturally decompose into the specified feedback mode. If transform feedback is set to GL_TRIANGLES, the draw command must supply GL_TRIANGLES, GL_TRIANGLE_STRIP, or GL_TRIANGLE_FAN. Providing incompatible inputs, such as submitting GL_LINES while feedback is configured for GL_TRIANGLES, causes a GL_INVALID_OPERATION.

De-indexing and Primitive Decomposition

Even though complex input topologies like strips and fans can be fed into the pipeline, the transform feedback mechanism does not record them as strips or retain index buffers.

OpenGL automatically decomposes connected primitives into independent, discrete components:

  • A triangle strip is broken down into separate, individual triangles consisting of three discrete vertices each.
  • A line strip is written as independent two-vertex line segments.

Consequently, vertices shared by adjacent primitives in strips or indexed draws are duplicated and written out sequentially in memory. The resulting transform feedback buffer will always contain a continuous array of completely independent points, lines, or triangles.
