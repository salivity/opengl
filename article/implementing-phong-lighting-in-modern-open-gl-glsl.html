Implementing Phong Lighting in Modern OpenGL GLSL

The Phong lighting model is a foundational illumination technique in computer graphics that approximates the interaction of light with surfaces by combining ambient, diffuse, and specular reflection components. Implementing this model in modern OpenGL requires configuring vertex data, transforming spatial coordinates and normal vectors into a unified coordinate space (typically view space or world space), and calculating the reflection physics within a GLSL fragment shader. Following the steps below will take you from shader setup to a fully lit 3D surface.

Step 1: Prepare Spatial and Material Uniforms

To calculate light interactions, the fragment shader requires geometric and photometric data. Pass the following inputs to your shaders:

  • Matrices: Model matrix, View matrix, Projection matrix, and the Normal matrix (the transpose of the inverse of the top-left 3x3 of the Model-View matrix) to correctly transform normal vectors under non-uniform scaling.
  • Light Properties: Light position (in world or view space), ambient color, diffuse color, and specular color.
  • Material Properties: Ambient reflectivity, diffuse reflectivity, specular reflectivity, and a shininess exponent (roughness factor).

Step 2: Implement the Vertex Shader

The vertex shader transforms object-space positions and normal vectors into the chosen reference space (view space is standard for numerical stability) and forwards them to the fragment shader.

#version 330 core

layout (location = 0) in vec3 aPos;
layout (location = 1) in vec3 aNormal;

out vec3 FragPos;
out vec3 Normal;

uniform mat4 model;
uniform mat4 view;
uniform mat4 projection;
uniform mat3 normalMatrix;

void main()
{
    // Transform vertex position into view space
    vec4 viewPos = view * model * vec4(aPos, 1.0);
    FragPos = vec3(viewPos);

    // Transform surface normal into view space
    Normal = normalize(normalMatrix * aNormal);

    gl_Position = projection * viewPos;
}

Step 3: Calculate the Ambient Component

Ambient lighting simulates indirect, scattered light present throughout an environment. It is computed as a constant factor multiplied by the light's color and the material's color:

vec3 ambient = lightAmbient * materialAmbient;

Step 4: Calculate the Diffuse Component

Diffuse reflection represents directional light scattered equally in all directions from a rough surface (Lambertian reflection). It depends on the angle between the surface normal (\(N\)) and the light direction vector (\(L\)):

  1. Normalize the incoming normal vector.
  2. Compute the normalized light direction vector pointing from the fragment to the light source.
  3. Calculate the dot product of \(N\) and \(L\), clamped to zero using max() to prevent negative lighting on surfaces angled away from the light.
vec3 norm = normalize(Normal);
vec3 lightDir = normalize(lightPos - FragPos); // In view space
float diff = max(dot(norm, lightDir), 0.0);
vec3 diffuse = lightDiffuse * (diff * materialDiffuse);

Step 5: Calculate the Specular Component

Specular reflection simulates the bright highlight seen on shiny surfaces. It depends on the angle between the viewer's line of sight (\(V\)) and the direction of the reflected light ray (\(R\)):

  1. Calculate the view direction vector pointing from the fragment to the camera (in view space, the camera is at vec3(0.0)).
  2. Calculate the reflection vector using GLSL's built-in reflect() function, which requires the incident vector pointing from the light toward the fragment (-lightDir).
  3. Calculate the dot product of the view vector and the reflection vector, clamp it to zero, and raise it to the material's shininess exponent.
vec3 viewDir = normalize(-FragPos); // Camera is at origin in view space
vec3 reflectDir = reflect(-lightDir, norm);
float spec = pow(max(dot(viewDir, reflectDir), 0.0), materialShininess);
vec3 specular = lightSpecular * (spec * materialSpecular);

Step 6: Assemble the Fragment Shader

Combine all three components to produce the final fragment color.

#version 330 core

in vec3 FragPos;
in vec3 Normal;

out vec4 FragColor;

uniform vec3 lightPos; // Must match coordinate space (view space)
uniform vec3 lightAmbient;
uniform vec3 lightDiffuse;
uniform vec3 lightSpecular;

uniform vec3 materialAmbient;
uniform vec3 materialDiffuse;
uniform vec3 materialSpecular;
uniform float materialShininess;

void main()
{
    // Ambient
    vec3 ambient = lightAmbient * materialAmbient;

    // Diffuse
    vec3 norm = normalize(Normal);
    vec3 lightDir = normalize(lightPos - FragPos);
    float diff = max(dot(norm, lightDir), 0.0);
    vec3 diffuse = lightDiffuse * (diff * materialDiffuse);

    // Specular
    vec3 viewDir = normalize(-FragPos);
    vec3 reflectDir = reflect(-lightDir, norm);
    float spec = pow(max(dot(viewDir, reflectDir), 0.0), materialShininess);
    vec3 specular = lightSpecular * (spec * materialSpecular);

    // Final Color
    vec3 result = ambient + diffuse + specular;
    FragColor = vec4(result, 1.0);
}

Step 7: Verify Matrix Alignment in Host Application

Ensure your OpenGL C++ host application generates and uploads the uniform variables accurately. The normalMatrix must be updated whenever the model or view matrix changes:

glm::mat3 normalMatrix = glm::transpose(glm::inverse(glm::mat3(view * model)));
glUniformMatrix3fv(normalMatrixLoc, 1, GL_FALSE, glm::value_ptr(normalMatrix));

Additionally, transform the world-space light position into view space on the CPU before uploading (glm::vec3(view * glm::vec4(worldLightPos, 1.0f))) so that all calculations within the fragment shader share identical coordinate spaces.
